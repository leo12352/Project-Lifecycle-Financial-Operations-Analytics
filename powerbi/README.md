# Power BI report work area

`dashboard.html` is a self-contained offline dashboard with four views. The four `dashboard_*.png` files are review screenshots. Run `python scripts/build_dashboard.py` after regenerating CSV data, then optionally `python scripts/capture_dashboard.py` to update screenshots (requires Playwright and Edge). See `POWER_BI_GUIDE.md` for native Power BI import and measures. The native four-page `Project_Lifecycle_Financial_Operations_Analytics.pbix` is included and was saved in Power BI Desktop.
